# 前端工作台视觉与交互

这次重构沿用现有页面、事件处理和单 HTML 内联构建。`frontend/src/app.css` 是唯一的样式表入口，按顺序加载基础样式与 `workbench.css`；后者承载共享色阶、按钮层级及连接页、服务器清单、终端工作区的视觉规则。新增界面优先复用 `--ui-heading` / `--ui-body` / `--ui-meta`、`--ui-gap` 和主题语义色，不再给常规标题加宽字距或用强调色表示每一个操作。

## 主题与布局

- 新浏览器默认使用 `standard-dark`。已有本机主题选择、旧键迁移、四套内置主题与自定义 Theme V4 JSON 均保留。删除最后一套自定义主题后回到默认主题。
- 尺寸与留白走主题的排版和密度变量；xterm 的字号仍用终端自身偏好。移动端表单保留 16px 的输入字号下限，服务器卡片的触屏操作保留 44px 点击区。
- Tailwind 透明度工具类基于 `color-mix()`，不会把 Theme V4 色值假定为裸 RGB 通道。液态玻璃保留独立的背景合成层和 35 秒漂移：卡片、列表、按钮不做嵌套模糊；仅在导航、遮罩和主要浮层使用滤镜。移动端内置玻璃主题继续以实底保证可读性。
- 首屏等待不挂载未确认的认证表单。服务器清单保留 6/6/3 分页、隐私掩码和复制行为；最近连接时间以相对时间呈现，完整时间仍可查看。终端桌面顶栏 48px，与抽屉顶部让位共享同一变量。终端祖先不做位移动画，以免改变内部 fixed 浮层的定位基准。

## 操作与状态

- 服务器清单中 `/` 聚焦搜索；服务器表单中 `Ctrl/⌘ + Enter` 提交，仍走原生校验和原有提交处理。快捷键不抢占 IME 或上层弹窗。终端搜索框内 `Esc` 关闭搜索并把焦点还给终端；普通终端输入的 Esc 语义不变。
- 握手摘要只消费已有的 SSH 状态事件，以当前标签和连接为单位；不会用 WebSocket 建立或认证成功冒充 Shell 就绪。保留原终端诊断；不显示估算百分比、虚构耗时或未确认的算法名。
- SFTP 继续使用既有进度与键盘选择；Agent 保留流式文本与完成后净化的 Markdown 渲染。通知使用三条有界队列，有关闭入口；错误默认不自动消失，不复制额外的诊断数据。
- 不做全站 fetch 拦截或每个网络请求的顶栏动画，不为界面新增递归删除进度协议，也不在支持多选与键盘导航的文件行上默认加 `content-visibility`。这些改动需要独立的可用性或性能验证，不应与皮肤重构绑定。

运行 `pnpm run verify` 验证类型、单元与集成测试、Worker 内联构建、Chromium 和移动 WebKit。修改内置色盘后执行 `pnpm run sync:theme-editor`。浏览器自动化不替代真机 IME、系统手势及 GPU 功耗测量。
