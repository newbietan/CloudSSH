不只是一个 Web 终端

连接、管理、传输与协作，都在一个标签页内。

CloudSSH 将终端、文件管理与智能运维组合为完整工作流，同时保持部署简单、边界清晰。

01

浏览器原生 SSH-2.0

纯 TypeScript 协议栈，支持 Curve25519、ECDH、AES-GCM/CTR、Ed25519、ECDSA 与 RSA，无需外部 SSH 库。

KEXcurve25519 CIPHERaes256-gcm HOST KEYed25519 / ecdsa / rsa
02

可视化 SFTP

目录浏览、上传下载、重命名与删除；支持多选、连续选择、批量任务、传输队列和取消。

/var/log backup.tar deploy.sh
03

AI 运维助手

BYOK 接入 OpenAI 兼容模型，理解终端上下文并调用 8 个运维工具；危险命令需要确认，高风险模式直接拦截。

真正可用的移动终端

适配软键盘、安全区、iOS 输入法、触摸选区和快捷键栏，手机 3 张、平板 6 张、桌面 9 张服务器卡片。

完整能力版图

常用能力已经连成一套，而不是散落的功能开关。

IDENTITY 身份与服务器管理

GitHub OAuth、已保存服务器、标签筛选与加密凭据存储。

TRUST 主机信任

首次连接展示 SHA-256 指纹，后续连接检测 Host Key 变化。

NETWORK 广泛连接兼容

IPv4 / IPv6 双栈，兼容 OpenSSH 与 Dropbear。

TRANSFER 两种文件流

可视化 SFTP 与 trzsz 原生终端传输并行可用。

PRIVACY 隐私展示与区域调度

IP 视觉掩码减少截图泄露；保存服务器时可借助 IPinfo 优化区域。

QUALITY 持续质量门禁

类型检查、单元与集成测试、可复现构建、E2E 与无障碍回归。

安全边界

明确每一段信任，也明确每一项限制。

CloudSSH 不以“浏览器工具”作为降低安全标准的理由。连接、身份、主机指纹、凭据和 AI 操作分别建立边界。

审查安全实现↗
01
分段加密

浏览器到 Worker 使用 HTTPS/WSS，Worker 到服务器使用 SSH-2.0。

02
TOFU 主机校验

首次展示 SHA-256 指纹，后续连接检测 Host Key 变化。

03
凭据内部流转

已保存凭据通过一次性令牌在服务端内部传递，不返回浏览器。

04
AI 操作确认

危险命令默认要求用户确认，禁止模式直接拒绝执行。

快速部署

从 Fork 到自己的 Web SSH，只需三步。

使用 Cloudflare Dashboard Git 集成或 Wrangler CLI。域名、OAuth 和 Turnstile 都是可选配置。

  1. 01
    Fork 仓库

    复制 CloudSSH 到自己的 GitHub 账号，保留后续同步上游的能力。

  2. 02
    连接 Cloudflare

    在 Workers & Pages 中连接仓库，使用项目内置构建配置。

  3. 03
    配置并访问

    按需添加 OAuth、Turnstile 和自定义域名，然后开始连接服务器。
